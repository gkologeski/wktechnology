# Acompanhar ligações pela Inbox
**Para que serve:** Ver todas as ligações das campanhas em uma lista própria, como no WhatsApp e no E-mail.
**Quem pode fazer:** Quem já vê a Inbox unificada; cada pessoa vê somente as ligações das conversas a que tem acesso.
**Onde fica:** Menu > TechSales > Inbox unificada > Ligações (`/inbox/ligacoes`).

## Passo a passo
1. Abra "Ligações" no menu da Inbox.
2. Busque pelo nome ou telefone, se necessário.
3. Selecione a ligação para ver duração, resumo, áudio, transcrição e reunião marcada.
4. Use "Abrir no canal" para continuar a conversa pelo WhatsApp.

## Observações
- A tela é somente leitura: ligações não têm resposta direta.
