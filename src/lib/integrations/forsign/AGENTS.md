# ForSign
- ForSign e-signature lives in `src/lib/integrations/forsign/` (thin `forsign.functions.ts`, all HTTP/DB in `forsign-service.server.ts`); webhook/cron only point at operations that are re-read from the ForSign API and evidence is written only by service-only `forsign_record_evidence`; why: unsigned payloads never become signature evidence.
- Signature positions and all-page rubrics use ForSign text tags (`#TE-ASSINA-N`, `#TE-RUBRICA-N`) planned by pure `forsign-placement.ts` and stamped invisibly by `forsign-pdf.ts` (including on a derived copy of frozen attachment packages without altering stored bytes); ambiguous or missing slots fall back to an appended "Página de Assinaturas"; why: signers never sign in the wrong slot and every page (including annexes) gets rubrics.
